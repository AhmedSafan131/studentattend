ESTIMATION BASIS
----------------
- Estimates represent focused engineering time for a developer already familiar with React, Laravel, MySQL, PWA, and this codebase.
- Ranges include implementation, unit/feature tests, integration fixes, code review preparation, and basic local verification.
- Estimates exclude production deployment waiting time, stakeholder meetings, requirements discovery before work started, and formal client UAT.
- 1 person-day = 8 engineering hours.
- Some commits contain both Frontend and Backend work; each task is counted only in its relevant section to avoid duplication.
- The estimates describe the size of the delivered scope, not elapsed calendar time.
